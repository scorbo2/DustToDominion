# Slider

This document proposes a new `dtd/widgets/slider.py` module containing a
UI widget for the game: `Slider`. This is a UI component that allows clicking
and dragging a tab control along a horizontal track to select a numeric value
within a bounded range. Vertically-oriented sliders are not supported.
A text label is provided to the left of the slider track, and small numeric
labeling options are provided running along the bottom of the track.
